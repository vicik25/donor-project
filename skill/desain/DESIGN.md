## Colour
*Strategy (restrained / committed / full / drenched) and the scene that decided light vs dark.*

| Role | Light | Dark | Used for |
|---|---|---|---|
| canvas |  |  | page background |
| surface / raised / sunken |  |  | cards, panels, wells |
| text / muted |  |  | copy |
| border / strong |  |  | dividers / input borders |
| action / on-action |  |  | primary buttons, links |
| focus |  |  | focus ring |
| success / warning / danger / info |  |  | state |

Contrast verified: *body >=4.5:1, large >=3:1, UI >=3:1, both themes (yes/no, how).*
